## What each area tests, as published

From S1 ("Test structure and subject areas"). Quotes are short; the page has fuller descriptions.

**Verbal reasoning (24)** has three item types:
- *A. Reading comprehension*: questions on passages; tests "the quality of the processing of the information".
- *B. Data/Statements*: some data and some statements; decide "whether each statement is true or false".
- *C. Verbal critical reasoning*: a short passage, then a question such as which condition would
  "best support the thesis"; candidates should assume the passage is true.

**Data insight (16)** has two item types:
- *A. Numerical critical reasoning*: "Tables, histograms, graphs, or simple passages", followed by several questions.
- *B. Data Sufficiency*: a problem with statements (1) and (2); decide which are "necessary, if any".

**Quantitative reasoning (10)**: "numerical and logical problems using basic mathematics and analytical thinking."
No topic list is published.

**What the 2024 sample (S8) looks like (described, not copied).** It has 40 numbered questions, not 50,
and states no time limit or scoring. Items show numbered options, usually four. Data sufficiency items use
a four-choice key (A: one statement alone suffices; B: both together; C: either alone; D: not sufficient),
which differs from the GMAT's five-choice key. Data/Statements items give a short list of data
next to lettered statements and ask which is necessarily true or false. Other items use passages, tables,
a histogram and a probability-density graph. Several quantitative items go beyond "basic mathematics": a
gradient of a two-variable function, a Type I error / null-hypothesis item, expected values of random
variables, and probability counting. The agent did not find an answer key in the extracted text.
S8 is a 2024 document not linked from the current page, so it may not reflect the AY 2027-28 form.

## Discrepancies with earlier records

1. **Navigation (config `unverified`, BOC-ADM-06).** Earlier: not published for this variant; the config
   assumes free navigation, and the only rules PDF found was the 2026-27 bachelor/law edition. Today a
   graduate-specific AY 2027/28 rules PDF (S6) exists and states 3 questions per screen, forward-only,
   no return to previous screens. The config's free-navigation assumption contradicts the published rule.
2. **Calculator.** Earlier: unverified. S6 lists calculators among prohibited items.
3. **Area order.** Earlier: not published. S1 says questions are mixed by difficulty and topic.
4. **Delivery and score report.** Earlier: only the bachelor/law rules were documented. S6 now documents
   graduate delivery (recorded, non-live proctoring; Safe Exam Browser; side phone camera), permitted
   materials, auto-submit, and a score report with per-area scores and correct/incorrect/unanswered counts.
5. **Response types (BOC-ADM-07).** Earlier register: no data-sufficiency response type documented for any
   Bocconi variant. S1 now describes Data Sufficiency items in Data insight, and S8 shows a four-choice key.
   Still single-select, but the item format exists.
6. **GRE threshold.** Earlier: "could not be verified". S4 now publishes a table of V/Q combinations.
7. **Who takes it.** Earlier records did not note that PPA and GLOBE need no test, that a separate
   Italian-applicant test exists, the "graduate by 2027" condition, or that earlier-year attempts and
   simulation scores cannot be used.
8. **Fees and windows.** EUR 60 per attempt, EUR 100 application fee, test window 16 July 2026 - 28 April 2027,
   and the attempt-spacing rules were not in earlier records.
9. **Quantitative content level.** S1 says "basic mathematics", but the 2024 sample includes multivariable
   calculus and inferential-statistics items. Unresolved; treat S1 as the current official description
   and S8 as an older illustration.
